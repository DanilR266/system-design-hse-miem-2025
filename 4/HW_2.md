## Пример
*Бронь отелей (Аналог букинга)*

1. Сервис авторизации и аутентификации
2. Сервис управления отелями (OMS)
3. Сервис бронирования
4. Сервис поиска и рекомендаций
5. Сервис отзывов
6. Сервис уведомлений
7. Сервис для интеграции с Aviasales

### Интеграции
1. Сервис авторизации и остальные: синхронная, для авторизации запросов
2. Сервис бронирования и сервис управления отелями: синхронная, на сервисе управления разместим информацию о наличии свободных комнат
3. Фронтенд и сервис уведомлений: асинхронная, можно сделать через вебсокеты


## Решение
### Сервисы и интеграции
1. Сервис аутентификации пользователя (для голосования и защиты от спама)
2. Сервис синхронизации с эфиром
3. Сервис обработки голосов пользователей
4. Сервис управления треками
5. Сервис уведомелний
6. Сервис сбора статистики

#### Интеграции
1. Обработка голосов, управление треками - синхронная, для мгновенного голосования и получения актуальных треков
2. Синхронизация с эфиром - асинхронная
3. Уведомления - может быть асинхронная, отправка результата голосования может быть отложено и/или вебсокеты
4. Аналитика - асинхронная
